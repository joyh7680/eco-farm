# ECO FARM — 잃어버린 초록 행성

Three.js로 렌더링하는 싱글플레이 3D 농장 게임입니다. 아그리아–7에 착륙해 제한된 물로 작물을 키우고, 가뭄을 견딘 수확물을 보급 기지에 납품하세요.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소를 여세요. 같은 네트워크의 태블릿에서는 `Network` 주소로 접속할 수 있습니다. 별도의 백엔드, 계정, API 키는 필요하지 않습니다.

페이지를 열면 우주선 접근·착륙 오프닝이 자동 재생됩니다. 착륙 후 미션 안내에서 **농장 운영 배우기**를 누르면 3D 농장 위에서 직접 조작하는 5단계 튜토리얼을 시작합니다. **튜토리얼 건너뛰고 임무 시작**으로 바로 시작할 수도 있습니다. 미션 안내는 자동으로 닫히지 않습니다. 사운드는 첫 클릭·터치 또는 키 입력 이후 활성화됩니다.

## 인터랙티브 튜토리얼

1. 강조된 **달빛 상추** 도구를 선택하고 빛나는 **1번 밭**을 눌러 심습니다.
2. **물주기** 도구를 선택하고 같은 밭에 물을 줍니다. 연습 물 10이 실제로 감소합니다.
3. 오른쪽 **성장률·수분 게이지**와 3D 작물을 관찰합니다. 연습 작물만 약 6초 만에 자랍니다.
4. **수확** 도구를 선택하고 다 자란 1번 밭을 눌러 보관함으로 옮깁니다.
5. **납품하기**를 눌러 연습 수익 +30G와 납품 진행을 확인합니다.

성공한 행동만 다음 단계로 진행시킵니다. 다른 도구와 밭, 단축키, 보조 조작으로 단계를 건너뛸 수 없습니다. 안내창과 화살표는 농장의 실제 클릭·터치를 방해하지 않으며, 임무·가뭄 시계는 연습 내내 멈춥니다. 일시정지하면 연습 작물의 성장도 멈춥니다.

**본격적인 임무 시작** 또는 연습 중 건너뛰기를 누르면 물 100, 300G, 빈 밭 6칸, 보관함 0개, 납품 0/4, 가뭄 이후 납품 0/2, 제한시간 08:00, 가뭄까지 70초로 초기화합니다. 수확·물 사용·수익 통계와 연출도 초기화하며 일반 게임은 원래 성장 속도를 사용합니다.

HUD의 **? 게임 방법** 또는 일시정지 메뉴의 **게임 방법 / 튜토리얼**은 현재 농장을 일시정지하고 조작 도움말을 보여줍니다. 닫으면 작물·자원·시간을 유지해 이어가며, 일시정지 메뉴에서 열었다면 정지 상태를 유지합니다. **튜토리얼 다시 연습하기**는 진행 초기화 안내를 먼저 표시하고, **초기화하고 연습 시작**을 눌렀을 때만 새 연습으로 전환합니다. 취소하거나 도움말을 닫으면 진행을 잃지 않습니다.

```sh
npm run build
npm run preview
```

배포 파일은 `dist/`에 생성됩니다. 정적 호스팅에서 실행할 수 있으며, WebGL 모듈 로딩을 위해 `index.html`을 파일로 직접 여는 대신 HTTP로 제공해야 합니다. 실행 중 외부 이미지·폰트·음원 요청이 없습니다.

## 조작

- **1 / 달빛 상추**: 도구 선택 후 빈 밭을 클릭·터치합니다. 15G, 성장 약 30초, 물 소모량이 많습니다.
- **2 / 별빛 콩**: 25G, 성장 약 45초, 물 소모량이 적습니다.
- **3 / 물주기**: 밭의 수분을 55 회복하고 물 10을 사용합니다. 수분이 100을 넘는 양은 버려집니다.
- **4 / 수확**: 다 자란 작물을 수확하거나 고사한 작물을 정리합니다.
- **5 / 납품**: 보관 중인 수확물을 전부 납품합니다. 월드의 `SUPPLY` 시설을 직접 눌러도 됩니다.
- 선택한 밭의 작은 상태 창에서 파종·물주기·수확을 바로 실행할 수도 있습니다.
- 달빛 상추는 민트빛의 둥근 잎과 초승달, 별빛 콩은 키 큰 줄기와 보랏빛 꼬투리·별로 구분합니다. 튜토리얼과 실제 임무 모두 밭마다 작물 이름·성장률·수확 가능 표시가 나오고, 보급 기지 보관함은 작물별 개수를 따로 표시합니다.
- 수확하면 해당 작물이 차례로 보급 기지 입구로 날아가 보관됩니다. 판매·임무 납품은 기존처럼 **납품하기**로 실행합니다. 일시정지 중에는 이동 효과도 멈추고, 새 임무·재연습 시 효과가 초기화됩니다. 동작 줄이기 설정에서는 짧은 도착 표시로 대신합니다.
- **Space / Escape**: 일시정지·계속하기. **Q**: SD/HD 렌더링 전환. **F3**: FPS·드로우콜·해상도 확인.
- 오른쪽 아래에서 음소거·품질·전체 화면을 조절합니다. 다른 탭으로 이동하면 게임은 자동 일시정지됩니다.

## 임무 규칙

초기 물 100, 자금 300G, 밭 6칸으로 시작합니다. 70초에 가뭄이 발생하며 수분 감소 속도가 2.25배가 됩니다. 수분이 15 미만이면 성장이 느려지고, 수분이 0인 채 22초가 지나면 고사합니다. 고사 전에는 물을 주어 회복할 수 있습니다.

8분 안에 작물을 **총 4개 이상 납품**하고, 그중 **2개 이상은 가뭄 이후 수확·납품**해야 성공합니다. 미리 4개를 납품해도 가뭄 조건을 충족해야 완료됩니다. 제한 시간이 끝나거나 남은 작물·수확물·자금으로 목표 달성이 불가능하면 실패합니다. 종료 화면에는 실제 수확량, 납품량, 수익, 물 사용량, 잔여 물, 환경관리 점수를 표시합니다.

처음에는 두 작물을 함께 심어 차이를 확인하세요. 가뭄이 오기 전 일부를 수확·납품하고, 나머지의 수분을 관리하면 첫 임무를 쉽게 완료할 수 있습니다. 물을 적게 쓰는 콩은 가뭄 시기에 유리합니다.

## 구현

- 페이지 진입 시 자동 재생되는 8초 우주 접근·행성 확대·착륙 연출과 스킵, 착륙 후 미션 안내 및 실제 행동 기반 연습 모드
- 고정 쿼터뷰, 실제 3D 밭·작물·기지·물탱크·보급 시설·우주선·온실·울타리·외계 식물
- Raycaster 기반 직접 조작, 밭 선택 강조, 네 단계 성장과 시듦·회복·고사
- 파종·물주기·수확·납품 파티클, 물탱크 잔량 변화, 가뭄의 지형·토양·잎 색상 변화
- Web Audio로 생성하는 효과음, 사용자 입력 후 오디오 활성화 및 음소거
- 독립적인 20Hz 고정 간격 재배 시뮬레이션, 정지·재시작·성공·실패 상태
- 마우스와 터치 입력, 가로 화면 우선 HUD, 페이지 스크롤 방지

그래픽은 프로젝트에서 절차적으로 생성합니다. 유료 또는 출처가 불분명한 외부 게임 에셋은 사용하지 않습니다.

## 코드

| 파일 | 역할 |
| --- | --- |
| `src/game/GameConfig.ts` | 성장 시간·수분·가격·가뭄·미션 목표 설정 |
| `src/game/GameState.ts` | 렌더러와 독립적인 게임 규칙·자원·상태·판정 |
| `src/game/Tutorial.ts` | 단계별 안내·허용 도구·연습 밭·전용 성장 시간 |
| `src/game/FarmScene.ts` | 3D 모델·맵·작물 표현·입력 판정·파티클·오프닝 |
| `src/game/Game.ts` | 게임 루프·고정 간격 업데이트·입력·상태 전환 |
| `src/game/Audio.ts` | 합성 효과음 |
| `src/ui/GameHUD.ts` | HUD·도구·시작·오프닝·결과 오버레이 |
| `src/styles/main.css` | 게임 UI와 화면 크기 대응 |

작물을 추가할 때는 `GameConfig.ts`의 작물 정의, `CropKind` 타입, 해당 3D 표현과 도구를 확장합니다. 밸런스는 `GameConfig.ts`에서 변경할 수 있습니다.

## 성능

SD 기본 내부 해상도는 높이 360px, 16:9에서 640×360입니다. 화면 비율을 유지하며 픽셀 단위로 확대하고, HUD는 기기의 실제 해상도로 표시합니다. HD는 높이 540px입니다. DPR을 1로 제한하고 실시간 그림자·후처리를 사용하지 않습니다. Geometry·Material을 공유하며, 고정 배경은 Material별로 병합하고 잔디·파티클에는 InstancedMesh를 사용합니다. 작물 모델은 미리 생성해 상태에 따라 재사용합니다.

**태블릿 실제 기기에서 30FPS 달성 여부는 별도 검증이 필요합니다.** 브라우저의 터치·해상도 에뮬레이션은 실제 GPU 성능을 증명하지 않습니다.

## 검증

```sh
npm test              # 재배·물·가뭄·회복·고사·납품·성공·실패·정지·초기화
npm run build        # 엄격한 TypeScript 검사 + 프로덕션 빌드
npm run test:browser # 먼저 npm run dev -- --port 5174 실행, 로컬 Chrome 필요
npm run test:crops   # 작물 구분·수확 이동·종류별 보관·정지·초기화·작은 화면 이름표 검증
npm run test:smoke   # 먼저 npm run preview -- --port 4173 실행
```

브라우저 테스트는 Playwright로 실제 3D 밭의 투영 좌표를 클릭합니다. 오프닝과 연습의 5단계, 자원·시간 초기화 후 일반 게임의 70초 가뭄과 성공까지 실제 시간으로 진행합니다. 시간 종료에 의한 실패만 테스트 전용 로컬 진입점에서 시뮬레이션 시간을 가속합니다. 잘못된 조작 차단, 타이머 정지, 도움말·재연습 확인/취소, 중간 건너뛰기, 재시작, 태블릿의 전체 튜토리얼과 화면 배치도 검증합니다.

`test-results/`에 장면별 스크린샷과 `report.json`이 생성됩니다. `GAME_URL`과 `BROWSER_CHANNEL` 환경변수로 서버 주소와 브라우저 채널을 변경할 수 있습니다. 브라우저 테스트 기본 주소는 `http://localhost:5174`, 프로덕션 스모크 테스트는 `http://localhost:4173`, 기본 채널은 `chrome`입니다. 테스트용 `window.ecoGame`은 로컬 호스트에서 `?test` 쿼리를 지정한 경우에만 노출됩니다.

확인한 결과:

- TypeScript 검사, 프로덕션 빌드, 핵심·튜토리얼 로직 테스트 14개 통과.
- 로컬 Chrome에서 실제 오프닝 → 5단계 연습 → 본 임무 초기화 → 임무 시간 72.25초에 4개 납품·성공까지 플레이. 가뭄 이후 수확물 2개와 물 사용량 20을 결과에 확인.
- 재시작 후 모든 자원·작물·이벤트 초기화, 시간 종료 실패 및 메인 화면 복귀 확인.
- 1024×768, 768×1024, 844×390 터치·DPR 2 에뮬레이션에서 전체 튜토리얼 완료, 자원 초기화, 일반 파종·물주기, 화면 안의 안내창·도구 배치와 스크롤 방지 확인.
- 데스크톱 headless Chrome 측정 표본: 연습 **60FPS / 137 드로우콜**, 일반 게임 **60FPS / 140 드로우콜**, 내부 해상도 576×360. 측정 환경의 표본이며 실제 태블릿 GPU 성능을 보장하지 않습니다.
- 프로덕션 빌드에서도 시뮬레이션 시간을 가속해 자연적인 수분 고갈·시듦, 물주기 후 3D 잎 색상 회복·성장 재개, 실제 3D 보급 시설 클릭 납품, 고사 및 밭 정리를 확인. 외부 네트워크 요청과 브라우저 런타임 오류 없음.
