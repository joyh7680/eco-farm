# ECO FARM — 잃어버린 초록 행성

기존 Three.js 농장과 재배·미션 규칙을 재사용하는 2.5D 농장 게임입니다. 실제 3D 모델과 고정 각도의 캐릭터 추적 카메라를 사용하며, 우주 캐릭터로 황폐한 농장을 탐색하고 직접 복구합니다.

기본 플레이는 **CHAPTER 01 — 버려진 농장 복구**입니다. 기존 카메라·캐릭터·이동·조이스틱·렌더링 환경을 사용하고, 챕터 맵에 맞게 배치와 충돌을 확장합니다. 기존 작물 재배와 가뭄 임무는 메뉴의 **기존 재배 연습 모드**에서 이용할 수 있습니다. 이 모드는 이전 기능을 보존하기 위한 별도 모드이며 챕터 2가 아닙니다.

## 실행

Node.js 20.19+ 또는 22.12+에서 실행합니다.

```sh
npm ci
npm run dev
```

같은 네트워크의 태블릿에서는 터미널에 표시되는 Network 주소로 접속합니다. 서버·계정·API 키가 필요하지 않으며, 외부 이미지·폰트·음원을 요청하지 않습니다.

```sh
npm run build
npm run preview
```

배포 산출물은 `dist/`입니다. WebGL 모듈을 로드할 수 있도록 HTTP로 제공하세요.

## CHAPTER 01 — 버려진 농장 복구

농경지는 기존과 같은 크기의 **3×3, 총 9칸**입니다. 나무·연구 건물·보급 기지·온실·물탱크·로버·꽃밭·가로등·정돈된 포장길은 챕터 화면에서 제거했습니다. 메마른 흙과 균열, 돌, 마른 풀, 부서진 울타리 흔적으로 방치된 분위기를 표현합니다. 착륙 우주선과 캐릭터는 유지하며, 삭제된 시설 자리에는 보이지 않는 충돌이 남지 않습니다. 챕터의 경작 목표는 가운데 줄 3칸이며 기존 저장 진행도와 오브젝트 ID를 보존합니다. 기존 재배 연습은 별도의 원래 환경과 충돌 배치를 사용합니다.

1. 우주에서 우주선이 비행하고, **갈색 흙·파란 물·초록 식물**이 보이는 행성에 접근합니다. 화면을 부드럽게 전환한 뒤 고정 각도의 2.5D 시점으로 물가 옆 육지에 착륙하고 문을 열어 기존 캐릭터가 내립니다. 약 **12.4초**이며 **오프닝 건너뛰기**로 생략할 수 있습니다.
2. 착륙 지점은 농장에서 떨어져 있습니다. AI 안내 후 **WASD / 방향키 / 조이스틱으로 직접 걸어서** 육지 쪽을 탐색해야 버려진 농장을 발견합니다. 발견 대화 후 빛나는 농경지에 접근해 **E / 조사하기**를 누릅니다. 오프닝을 건너뛰어도 농장 발견까지의 걷기는 생략되지 않습니다.
3. 가운데 줄 위쪽 통로에 있는 **잡초 5개**를 제거합니다. 도달 가능한 가장자리 잡초와 밭 안의 연결된 잡초가 함께 사라집니다.
4. 밭 사이 통로의 **돌 3개**를 하나씩 들어 오른쪽 아래의 테두리가 있는 수거 장소까지 운반해 내려놓습니다. 집어 든 돌은 캐릭터 손에 표시되며 내려놓기 전에는 진행도가 늘지 않습니다.
5. 앞서 정리한 가운데 줄 농경지 **3칸**에 가까이 가서 괭이질합니다. 흙 파티클·도구 동작·효과음과 함께 고르지 않은 흙이 경작된 흙고랑으로 바뀝니다.
6. **농경지 복구 완료! / CHAPTER 01 CLEAR**, 밝아지는 농경지, 복구율 **0% → 12%**와 다음 이야기 **CHAPTER 02 — 메마른 농장**을 표시합니다. 물탱크 복구·새 재배 시스템·새 가뭄 이벤트는 구현하지 않습니다.

좌측 상단에는 현재 미션만 작은 HUD로 표시합니다. 작업 대상에 은은한 고리와 목적지 안내가 나타나며, 화면 밖 목적지는 가장자리 화살표로 안내합니다. 잡초 경쟁, 돌 제거와 안전, 토양·배수·작물 간격을 짧게 설명하며, 토양에 따라 경운의 필요성과 방법이 다르다는 점을 포함합니다.

챕터 조작은 **WASD / 방향키**, **E**, **Enter / Space** 대화, **Esc** 대화 닫기 / 메뉴입니다. 태블릿은 기존 왼쪽 조이스틱·오른쪽 행동 버튼과 대화 터치만으로 진행할 수 있습니다. 대화 중에는 이동을 멈추며 중복 작업 입력을 차단합니다. 물탱크와 기존 씨앗 단축키는 챕터 미션 중에는 동작하지 않습니다. 챕터에서는 기존 재배·가뭄 타이머를 진행시키지 않습니다.

진행은 `localStorage`의 `eco-farm.chapter-01.v1`에 저장합니다. 농장 발견·작업 완료·대화 진행마다 즉시 저장하고 위치는 1초 간격, 탭 숨김·페이지 종료 시에도 저장합니다. 농장 발견 여부·잡초·수거된 돌·경작된 흙·들고 있는 돌·남은 대화·안전한 위치를 복원합니다. 이전 저장 기록도 이어갈 수 있습니다. 작업 도중 새로고침하면 완료하지 않은 작업은 다시 할 수 있습니다. 저장소 접근이 차단되면 안내를 표시하고 현재 플레이를 계속합니다. **새 오프닝을 처음부터 보려면 메뉴 → 챕터 1 초기화 → 초기화하고 처음부터 시작**을 누릅니다. 메뉴에서 기존 재배 연습을 이용한 뒤 **CHAPTER 01 계속하기**로 복귀할 수 있습니다.

## 기존 재배 연습 모드 조작

| PC | 동작 |
| --- | --- |
| WASD / 방향키 | 화면 방향을 기준으로 캐릭터 이동 |
| 1 | 선택한 씨앗 심기 |
| 2 | 물주기 |
| 3 | 수확 / 고사 작물 정리 |
| E | 현재 근처 대상에 맞는 행동 |
| Esc / Space | 취소·일시정지 메뉴 / 계속하기 |
| M | 캐릭터 따라가기 / 농장 전체 보기 |
| Q / F3 | 자동·선명 화질 전환 / FPS·드로우콜 표시 |

하단 중앙의 작은 씨앗 주머니에서 달빛 상추 또는 별빛 콩을 선택합니다. 상단에는 물·자금·보관함만 표시하며, 주머니를 누르면 세부 잔량과 작물별 보관 개수가 펼쳐집니다. 임무 칩을 누르면 가뭄 이후 납품 조건과 카운트다운을 확인할 수 있습니다. 우측 상단의 지도 버튼 / M은 농장 전체 보기이며, 메뉴 안에서 도움말·음소거·화질·전체 화면을 조절합니다. 밭·시설 가까이 접근해야 작업할 수 있습니다. 원거리 클릭·상태 창·단축키로 거리 제한을 건너뛸 수 없습니다. 가까운 밭은 테두리가 강조되고 상태가 표시됩니다.

태블릿에서는 왼쪽 아래 조이스틱으로 이동하고 오른쪽 큰 행동 버튼을 누릅니다. 빈 밭에서는 심기, 자라는 작물에서는 물주기, 다 자랐거나 고사한 작물에서는 수확·정리로 바뀝니다. 오른쪽 작은 버튼으로 심기·물주기·수확을 직접 지정할 수도 있습니다. 물탱크에서는 물 채우기, SUPPLY 보급 기지에서는 납품하기로 바뀝니다. 씨앗 선택·튜토리얼·메뉴·재시작까지 모두 터치로 조작할 수 있습니다. 조이스틱과 행동 버튼은 동시에 터치할 수 있습니다.

건물·밭·주요 시설·나무·울타리는 통과할 수 없습니다. 대각선 이동 속도를 제한하고, 느린 프레임에서도 충돌을 세분화하며, 벽 옆에서는 미끄러지듯 이동합니다. 조이스틱을 놓거나 터치가 취소되거나 게임을 정지하면 이동 입력을 해제합니다. 탭을 비우면 게임이 일시정지됩니다.

## 물과 재배

초기 전체 물 **100** 중 **20**은 물뿌리개에, **80**은 물탱크에 있습니다. 휴대 한도는 **30**입니다. 물탱크에 접근해 E / 물 채우기로 옮겨 담으세요. 충전은 전체 물을 늘리지 않습니다. 물주기는 휴대 물과 전체 물을 각각 10 줄이고 토양 수분을 55 회복합니다. 탱크 수위와 HUD는 탱크·휴대 잔량을 구분합니다.

- 달빛 상추: 씨앗 15G, 성장 약 30초, 판매 30G. 민트빛 둥근 잎·초승달.
- 별빛 콩: 씨앗 25G, 성장 약 45초, 판매 50G. 키 큰 줄기·보라 꼬투리·별. 물을 적게 사용합니다.
- 수분 15 미만이면 성장 둔화, 수분 0으로 22초 유지되면 고사합니다. 고사 전에는 물로 회복할 수 있습니다.
- 수확물은 기존 이동 효과와 함께 보급 기지 보관함에 저장됩니다. 판매·미션 납품은 캐릭터가 기지에 도착해 실행합니다.
- 새싹이 달린 둥근 헬멧, 눈과 볼터치, 부드러운 방향 전환·걷기·작업 자세·물뿌리개·파티클·효과음으로 행동을 표현합니다. 나무나 건물 뒤에서는 캐릭터 실루엣으로 위치를 알려줍니다. 동작 줄이기 설정은 이동 진폭과 수확 효과를 줄입니다.

## 튜토리얼과 임무

메뉴 → **기존 재배 연습 모드**에서 **농장 운영 배우기** 또는 **튜토리얼 건너뛰고 임무 시작**을 선택합니다.

1. 조이스틱 / WASD로 빛나는 1번 밭에 접근해 상추 심기.
2. 밭 옆에서 물주기. 물탱크에 방문해 충전하는 방법 안내.
3. 성장·수분 관찰. 연습 작물만 약 6초 만에 성장하며 자유롭게 이동 가능.
4. 1번 밭으로 돌아와 수확.
5. SUPPLY 기지까지 직접 이동해 납품.

연습은 짧은 말풍선으로 안내합니다. `?` 버튼으로 자세한 설명을 펼칠 수 있고, 연습 대상이 화면 밖에 있으면 가장자리 방향 안내가 나타납니다. 연습 중 임무·가뭄 시계는 정지합니다. 올바른 밭·행동만 연습 단계를 진행시킵니다. 연습 완료·건너뛰기로 본 임무를 시작하면 캐릭터 위치, 물 100(휴대 20), 300G, 빈 밭 6칸, 통계·납품량·효과·타이머를 초기화합니다. 도움말은 현재 진행을 정지하고 보존하며, 재연습은 초기화 확인 후 시작합니다.

기존 임무 규칙을 유지합니다. 70초 후 가뭄으로 수분 감소가 2.25배가 됩니다. 8분 안에 **총 4개 납품**, 그중 **최소 2개는 가뭄 이후 수확·납품**해야 성공합니다. 제한 시간 종료·목표 달성에 필요한 자금과 작물 부족은 실패로 처리합니다. 결과에는 수확·납품·수익·물 사용·환경관리 점수를 표시합니다.

| `src/game/ChapterOne.ts` | 챕터 상태·거리 및 순서 검증·작업 완료 반영·저장과 복원 |
| `src/game/ChapterScenery.ts` | 같은 2.5D 맵의 잡초·운반 돌·수거 장소·황폐한 흙·우주선 문·괭이 |
| `src/game/Arrival.ts` | 우주 비행·행성 접근·착륙·하선의 시간표와 착륙 지점 |

| `src/game/GameState.ts` | 기존 작물·가뭄·미션 시뮬레이션과 휴대 물 관리 |

기존 20Hz 고정 간격 재배 시뮬레이션을 유지합니다. 카메라는 회전하지 않고 캐릭터를 부드럽게 따라가며, 세로 화면에서는 가로 방향으로 최소 17월드 단위를 확보합니다. 전체 보기에서는 농장을 한눈에 보여주고, 새 임무를 시작하면 추적 모드로 돌아옵니다. 동작 줄이기 설정에서는 카메라 보간을 생략합니다.

360p 픽셀 확대를 없애고 안티앨리어싱과 부드러운 텍스처 필터링을 적용했습니다. 기본 약 105만 픽셀, 선명 화질 약 185만 픽셀의 내부 해상도 상한을 사용하며 DPR 확대는 최대 1.5입니다. 32FPS 미만이 3초 구간 두 번 연속 측정되면 해상도 배율을 단계적으로 낮춥니다. 화질 버튼으로 배율을 초기화할 수 있습니다. UI는 렌더링 해상도와 독립적으로 선명하게 유지합니다.

실시간 그림자·후처리를 사용하지 않고 부드러운 접지 그림자를 공유 텍스처로 표현합니다. 정적 배경은 Material별 병합, 잔디·파티클은 InstancedMesh, 작물·캐릭터는 공유 Geometry·Material을 사용합니다. 상태 텍스트는 10Hz, 카메라·캐릭터와 가까운 밭 말풍선의 위치는 렌더 프레임마다 갱신합니다. 상시 작물 이름표와 큰 관리 패널을 제거했습니다. 외부 게임 에셋은 사용하지 않습니다.

**실제 태블릿 30FPS는 기기에서 별도 측정이 필요합니다.** 데스크톱 Chrome의 터치·DPR 에뮬레이션은 실제 GPU 성능을 보증하지 않습니다. F3로 기기에서 FPS와 드로우콜을 확인할 수 있습니다.

## 검증

```sh
npm test              # 발견·저장·운반·착륙지→9칸 경로 + 기존 재배·이동·충돌·카메라 (34개)
npm run build         # 엄격한 TypeScript 검사 + 프로덕션 빌드
npm run test:chapter  # dev 서버 http://localhost:5174, 챕터 전체 키보드·터치 플레이
npm run test:browser  # dev 서버 http://localhost:5174, 로컬 Chrome
node scripts/cozy-ui.mjs # 추적·전체 보기·주머니·메뉴·해상도·반응형 화면
npm run test:crops    # 캐릭터 경로를 포함한 동일 통합 회귀 검증
npm run test:smoke    # preview 서버 http://localhost:4173에서 통합 검증
```

챕터 브라우저 검증은 `scripts/chapter-playtest.mjs`입니다. 실제 키보드·CDP 터치 입력으로 경로를 이동하며 캐릭터 순간 이동이나 미션 상태 강제 완료를 사용하지 않습니다. 1280×800 키보드와 1024×768 터치 전용으로 챕터 전체를 진행하고, 768×1024·844×390·390×844에서 터치 이동·조사·대화·HUD 배치를 검사합니다. 원래 시점의 착륙·문 열림·캐릭터 등장, 화면 오브젝트 소멸·변화, 돌을 든 상태의 새로고침, 클리어 저장·초기화·기존 재배 모드 복귀도 확인합니다. 결과와 스크린샷은 `test-results/chapter-report.json`, `chapter-*.png`에 저장합니다. 실제 태블릿 GPU의 30FPS 보장은 별도 기기 측정이 필요합니다.

2026-11-09 최종 검증 결과: 빌드, 단위 테스트 **34개**, PC·터치 챕터 전체 플레이, 5개 화면 배치, 기존 재배·가뭄 납품 회귀 검증이 통과했습니다. 우주 비행 → 갈색·파란색·초록색 행성 접근 → 별도 착륙지 하선 → 실제 입력으로 걸어서 농장 발견 → 복구 완료를 확인합니다. 오프닝 건너뛰기 후에도 걸어가야 농장을 발견하며, 발견 여부·작업 진행·운반 중인 돌·초기화도 검증합니다. 착륙지에서 밭 9칸까지 연결된 경로와 물·우주선 충돌을 검사합니다. 화면은 `test-results/arrival-planet-approach.png`, `arrival-explore-shore.png`, `chapter-*-discovery.png`에 저장했습니다. 게임 진행을 보존하므로 새 오프닝은 메뉴의 챕터 초기화로 다시 볼 수 있습니다.

브라우저 검증은 `scripts/character-playtest.mjs`를 사용합니다. `GAME_URL`과 `BROWSER_CHANNEL`로 주소·브라우저 채널을 바꿀 수 있습니다. `window.ecoGame` 진단 객체는 localhost의 `?test` 진입에서만 노출됩니다. 테스트는 캐릭터 위치를 순간 이동시키지 않습니다. 키보드 / 실제 멀티터치 이벤트로 통로를 이동하며 전체 튜토리얼, 원거리 작업 차단, 물탱크 충전, 입력 취소·정지, 두 종류 작물, 가뭄 이후 납품과 미션 성공을 검증합니다. 긴 대기만 재배 시뮬레이션 시간으로 가속합니다.

1280×800 키보드와 1024×768 터치 전용 전체 플레이, 768×1024·844×390 터치 배치와 이동을 검사합니다. 스크린샷과 결과는 `test-results/character-*.png`, `test-results/character-report.json`에 저장합니다.

새 화면 검증은 `scripts/cozy-ui.mjs`를 사용합니다. 1280×800, 1024×768, 768×1024, 844×390, 390×844에서 카메라 추적·전체 보기, 화면 안의 UI 배치, 자원 주머니, 메뉴·도움말·재연습, 느린 프레임의 해상도 하향을 검사합니다. 별도의 실제 시간 RAF 표본으로 FPS를 측정하며 이는 데스크톱 Chrome 표본입니다. `test-results/cozy-report.json`과 `cozy-*.png`에 결과를 저장합니다.
